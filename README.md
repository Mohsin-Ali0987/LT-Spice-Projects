# Engineering Projects Portfolio

A collection of analog circuit design and power electronics simulation work.

## Projects

### 🔬 [Photodiode TIA – Position Sensor Circuit](./photodiode-tia-position-sensor)
LTspice design and noise analysis of a transimpedance amplifier (TIA) front-end for a laser position-sensing photodiode array, with two selectable polarity configurations (Legacy / Pangolin) and shot-noise characterization across illumination-split sweeps.

**Tools:** LTspice · Analog front-end design · Noise analysis

### ⚡ [MATLAB / Simulink Power Electronics Projects](./matlab-simulink-projects)
A set of Simulink models covering multilevel inverter topology, three-phase impedance measurement, and a wind + solar hybrid grid-tied power system.

**Tools:** MATLAB · Simulink · Simscape Power Systems
